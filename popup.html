LinkedIn Mass Unfollower

What it Does

This tool will automatically unfollow all your LinkedIn connections in either the 'Following' or 'Followers' sections.

How it Works

  1. We will redirect you to the appropriate LinkedIn page.
  2. It will unfollow users one by one (this cannot be changed due to how LinkedIn works).
  3. It first checks if there are any people you follow, if it doesnt find any on the page, it will scroll down till it finds ones that you are following.
  4. If there are no more visible users, it will scroll down to load more. The default wait time between sections is 3.5 seconds to ensure the page loads properly
  5. If no additional users are found, it will refresh the page and check one more time.
  6. After completing one section, you'll have the option to continue with the other section.

Important Notes

  • After processing the 'Following' section, at least 9 users will remain to avoid LinkedIn's bot detection.
  • Keep the page and browser open until the process completes.
  • Average completion time: ~1 user per second.
